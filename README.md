# BahrainExplore

## Description

BahrainExplore is a simple web application that allows users to create and store a list of places they want to remember when they visit Bahrain. Whether it's for future trips or to keep track of interesting locations, users can easily save the names, locations, categories, and descriptions of places, making it easy to access their personalized list whenever they come to Bahrain. The platform is designed to help users organize and remember their favorite spots, from restaurants to landmarks, ensuring they never miss out on a great place.

### Features:

* View the Home (Guest) Page with general information.
* Explore places without signing up.
* Sign Up / Sign In to access personalized features.
* Home (User) Page displays a customized experience.
* Community Page to explore places shared by others.
* Upload image insted of putting a linl.
* Add a Place to save locations of interest.
* Show All Your Places in an organized list.
* Place Details Page for in-depth information on each saved location.
* Edit Page to update place information.

### Technologies Used:

* Frontend: HTML, CSS, JavaScript, Bootstrap
* Backend: Node.js, Express
* Database: MongoDB
